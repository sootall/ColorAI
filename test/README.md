# 交班好好說：護理交班結構與同理溝通練習平台

> Gate 2 學生示範專案。全部組員、需求與資料均為教學虛構；目前**只有開發前規劃文件，尚未開發程式或完成實測**。

## 小組基本資料
- 示範第○組：林小安（協調／流程）、陳子晴（護理內容／驗收）、王樂文（設計／技術）；三人僅供示範，課堂實際以4–5人分組。
- Gate 1 主題來源：整合「SBAR練練看」與「同理回應練習室」；小組自行決定不納入語音與真實醫療資料。

## 目的與 MVP
讓護理學生閱讀虛構病例，自行撰寫 SBAR 與一段尊重、清楚的交班溝通語句，獲得**可追溯的規則式**缺漏提示並重新修訂。
- F01：選擇模擬病例並閱讀資料
- F02：自行輸入、暫存、取回 SBAR 四欄與溝通句
- F03：檢核必填欄與案例必要資訊、顯示可編輯回饋

## 現況／限制
- `src/` 與 `tests/` 目前為空（使用 `.gitkeep`）；Gate 2 不要求程式。
- 僅使用虛構案例，**不可輸入真實病人資訊**；不連醫院 HIS/EHR，不做醫療決策。
- AI 生成回饋和臨床評分目前不自動執行；由專家核對的規則為 MVP 方向。
- 後續開發建議 HTML/CSS/JS + localStorage，無須付費 API；需確認瀏覽器環境及資料清除方式。
